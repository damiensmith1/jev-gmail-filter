# Security policy

Please **don't open a public issue** for security problems. Report them
privately through GitHub:
[Report a vulnerability](https://github.com/damiensmith1/jev-gmail-filter/security/advisories/new).

Include what you found, how to reproduce it, and the version or commit
affected.

This app runs locally and handles Gmail access. Never include your own
OAuth credentials, tokens, API keys or email content in a report.
